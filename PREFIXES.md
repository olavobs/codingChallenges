# Legenda de prefixos

Cada arquivo `.java` deste repositório é prefixado com a sigla da estrutura de
dados ou técnica usada para resolver o problema, no formato `SIGLA_NomeDoProblema`.

| Sigla | Técnica / Estrutura de dados |
|-------|-------------------------------|
| `TP`  | Two Pointers |
| `SW`  | Sliding Window |
| `HM`  | HashMap |
| `HS`  | HashSet |
| `ST`  | Stack |
| `BS`  | Binary Search |
| `PQ`  | Priority Queue / Heap |
| `SRT` | Sorting |
| `PS`  | Prefix Sum |
| `MA`  | Math / Aritmética modular |
| `BF`  | Brute Force / Simulação (sem estrutura especial) |
